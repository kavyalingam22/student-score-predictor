# Student Score Predictor

## Overview
This project predicts student exam scores based on study hours using a simple Linear Regression model.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Features
- Predicts score based on input hours
- Visualizes data using graph
- Demonstrates basic machine learning workflow

## Example Output
Enter study hours: 6  
Predicted Score: 65.89

- Training a Linear Regression model
- Making predictions using sklearn
